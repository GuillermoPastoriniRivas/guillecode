# GuilleCode 0.14.1 — Equipos IA y skills con guardas

- Modo Equipos IA integrado: Lead y especialistas con modelos propios, planificación, revisiones, correcciones y QA manual posterior.
- 13 skills completas: Frontend, Backend, GraphQL, AWS, Docker, QA, DevOps, Database, Security, Code Review, Team Lead, Comportamientos y Git Integration.
- Perfiles combinables por integrante; guardas de autorización, validación, concurrencia, accesibilidad, errores y evidencia real. El perfil Code Review quita herramientas de edición.
- Actualización del catálogo sin reemplazar skills personalizadas ni modificar snapshots históricos. Las plantillas sin skills del Lead reciben Team Lead y Comportamientos.
- Capturas reales antes/después, comparador, deslizador, ampliación e historial. Capturas alteradas o ausentes no se muestran como verificadas.
- Presupuestos, retención opcional y recuperación de app/motor sin repetir ciegamente operaciones.
- Carpetas con o sin Git: el runner registra y compara archivos sin crear `.git`, preserva trabajo previo y recupera la misma instantánea después de reiniciar.
- Canal firmado propio de Kaitach/guillecode. Las publicaciones de esta edición conservan sus cambios; el endpoint del upstream sigue protegido.
- Instalador y paquete ZIP de skills compatibles con OpenCode. Se verifican producto, versión, huella y firma antes de publicar.

Las comprobaciones de integración usan herramientas reales e inferencia determinista local. No equivalen a una aceptación con modelos de producción ni sustituyen el QA manual del usuario.
